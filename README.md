## 🟡 what is UwUnity tOwOl ?

during world building in Unity
*(whether for General Game Development or VRChat World Building)*
we sometimes need to do tedious works which can actually be automated
as if for now we have 4 Modules :
- Module Generator
- transfOwOrm Controller
- GameObj Name Manager
- txt File to UI Text
<br>
<br>
<br>

## 📦 Module Generator

sometimes we want to generate repeated groups with certain smaller elements with probability
this module is mainly used to summon any GameObjects / Prefabs based on a probability distribution
<br>
<br>
<br>

## 📍 transfOwOrm Controller

sometimes we want to
- scatter things (in a cuboid or circular or spherical area)
- place game Objects around the parent
- snap game objects onto grids
- place a group of objects into an ordered matrix
- *(and so on)*

of course this can be done by hand
*but this is painful and time consuming*
this is what transfOwOrm Controller was made for
<br>
<br>
<br>

## 🏷️ Game Object Name Manager

sometime we want to rename a group of Game Objects with an increasing index
chances are we have to rename them one by one
now we can do it in a single click OwO
<br>
<br>
<br>

## 📝 txt File to UI Text

convert a txt file to a bunch of UI Text
where in the txt file, each line will be it's on UI Text
this can be used for
- lyrics visualization
- random string picker
- random topic generator
<br>
<br>
<br>

## 🎯 the Aim of UwUnity tOwOls

to make painful Unity work into simple work
